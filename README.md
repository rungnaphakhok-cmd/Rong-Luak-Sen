# โครงงานเว็บไซต์โปรโมทร้านโรงลวกเส้น (Rong Luak Sen)

เว็บไซต์นี้พัฒนาขึ้นเพื่อเป็นส่วนหนึ่งของโครงงานคอมพิวเตอร์ด้านการส่งเสริมการตลาดและการประชาสัมพันธ์ออนไลน์ให้กับร้านโรงลวกเส้น ในพื้นที่ชุมชนร่มเย็น (ROM YEN)

## 📌 วัตถุประสงค์
1. เพื่อประยุกต์ใช้เทคโนโลยีสารสนเทศในการพัฒนาเว็บไซต์โปรโมทร้านค้า
2. เพื่อเพิ่มช่องทางการประชาสัมพันธ์และขยายฐานลูกค้าให้แก่ร้านโรงลวกเส้น
3. อำนวยความสะดวกให้ผู้สนใจเข้าชมเมนูอาหารและข้อมูลการติดต่อผ่านออนไลน์

## 🛠 เทคโนโลยีที่ใช้
- **HTML5** : โครงสร้างหลักของเว็บไซต์
- **Tailwind CSS** : การจัดตกแต่งสไตล์และรองรับอุปกรณ์มือถือ (Responsive Design)
- **JavaScript** : ระบบโต้ตอบผู้ใช้และการกรองหมวดหมู่เมนู
